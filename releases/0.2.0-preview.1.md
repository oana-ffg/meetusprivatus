# Meetus Privatus 0.2.0-preview.1

**Meetus Privatus is now a Windows app.** The command line is gone.

- **Start and stop with a button.** Open the app, press Start recording, press Stop recording.
- **Follow along.** Text appears as the meeting goes, usually 20 to 40 seconds behind, labelled Mic or Playback.
- **Summary with action items.** A local AI model writes an overview, action items with owners and deadlines, decisions, and key points when you stop. Each action item links to its moment in the transcript. Nothing leaves your PC.
- **CPU or GPU.** Summaries use the CPU by default. A setting runs them on the GPU through Vulkan, and they fall back to the CPU if that does not work. Transcription always stays on the CPU.
- **Prior meetings.** They are listed in the app, with readable titles once summarized.
- **Hidden from screen sharing by default.** Live text can include notes you spoke while muted, so the window stays out of screen shares and screenshots. You can turn this off in Settings.
- **Updates in the app.** Press Check for updates, then Restart to update. The app never checks by itself.

**Installing:** download `MeetusPrivatus-win-x64-Portable.zip`, extract it into a local folder, and open `Meetus Privatus.exe`. The first time you want a summary, press the download button for the model (about 2.7 GB, one time). Transcripts work without it.

**Coming from an earlier preview:** the old `Update.cmd` cannot install this version, so install the ZIP once. Your settings carry over. Move your old `transcripts` folder beside `Meetus Privatus.exe` if you want those meetings listed.

**This is still a preview.** It has been tested with public audio and invented meetings. Real Zoom and Teams calls, accents, summary quality on real meetings, and low-powered laptops have not been validated. Summaries can miss or misstate things, so check anything important against the transcript. Releases are not code-signed, so Windows may warn before opening them.
